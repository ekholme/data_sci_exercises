# Data Sci Exercises

A workspace for polyglot data science exercises and katas

## Contents

### Simulation

- [Sampling from a Multivariate Normal Distribution in Julia](src/sim_mvnorm.jl): A small example illustrating how to draw a sample from a multivariate normal distribution.

### Statistical Modeling

- [Maximum Likelihood Estimation in Julia](src/mle_linreg.jl): Estimating the parameters of a linear regression using maximum likelihood estimation.

- [Basic Logistic Regression in Julia](src/logistic_regression.jl): Simulating a dataset, then fitting a 'vanilla' logistic regression, extracting model coefficients, and measuring model accuracy.

- [Estimating Bootstrapped Percentiles in R](src/bootstrap_percentile_estimates.R): Simulating a dataset, then implementing a function to bootstrap estimate percentiles from the data.

### Structural Equation Modeling

- [Basic Confirmatory Factor Analysis in Julia](src/cfa.jl): Simulating data, then fitting a 1-factor CFA model with 4 observed variables.

### Probability

- [Romeo and Juliet in Julia](src/romeo_juliet.jl): Estimating the probability that Romeo and Juliet will meet in a given window (see file for full problem text).

### Misc Programming

#### R

- [Passing Dots in R](src/pass_dots_purrr.R): A minimal reproducible example demonstrating how to 'pass dots' to functions in R.
